# הסקטארוב — ערכת ניהול מכשירי MediaTek

תוכנה לניהול, שאיבה (Readback) וצריבה (Flash) של מכשירי MediaTek — ממשק גרפי בעברית מעל **mtkclient**, עם תמיכה ב-SP Flash Tool Scatter.

גרסה נוכחית: **0.7.3**

## ⚠️ אזהרות בטיחות

- **צריבת Preloader / LK שגויה עלולה להמית את המכשיר לצמיתות.**
- גבה תמיד לפני צריבה — התוכנה מגבה אוטומטית (אפשר לכבות בתיבת הסימון בלשונית הצריבה).
- מחיצות רגישות (preloader, lk, nvram, nvdata, seccfg, frp, efuse ועוד) מציגות אזהרה מודגשת לפני פעולה.
- אין ערבות — השימוש באחריותך בלבד.

## דרישות

- Windows 10/11
- **Python ניידת (MTKCliantPortable)** — מספקת את מפרש Python ואת PySide6. נתיב ברירת המחדל:
  `C:\Users\karnaf\Downloads\אנדרואיד\MTKCliantPortable\MTKCliantPortable`
  (ניתן לשנות במשתנה הסביבה `ASKATEROOV_PYTHON_ROOT`, או בעריכת הנתיב בראש `app\core\config.py`).
- **הכלים ארוזים בתוך הפרויקט** — אין צורך להתקין אותם בנפרד:
  - `tools\mtk\mtk.py` + `tools\mtk\mtkclient` — מנוע ה-mtkclient (מועדף על העותק שבתוך התיקייה הניידת).
  - `tools\adb.exe` ו-`tools\fastboot.exe` (עם קובצי ה-DLL הנלווים) — מתוך platform-tools.
  ניתן לעקוף את הנתיבים במשתני הסביבה `ASKATEROOV_ADB` / `ASKATEROOV_FASTBOOT`.
- **דרייברים:** ל-ADB ולמצב Fastboot דרוש דרייבר Android USB (דרכו Windows מזהה את המכשיר); למצב BROM דרוש דרייבר MediaTek VCOM/PreLoader או **UsbDk** (`usbdk.msi` בתיקייה הניידת, וגם כפתור התקנה בלשונית mtkclient).
  בכל אחת מהלשוניות (mtkclient, ADB, Fastboot) יש כפתור **🩺 בדיקת דרייבר** שבודק — קריאה בלבד — אם הדרייבר הנדרש לפעולה של אותה לשונית מותקן במחשב.

## כותרת מצב מכשיר (מעל הלשוניות)

מעל שורת הלשוניות מוצגת כותרת "מצב מכשיר" עם חיווי חי: דגם, מעבד, מצב בוטלאודר
ואחוז/מתח סוללה מסונכרן. העדכון אוטומטי (כולל בדיקה תקופתית) כשמכשיר מתחבר/מתנתק.
מתחת לכותרת נמצא מד ההתקדמות, ומתחתיו הלשוניות. מה שמוצג תלוי במצב החיבור:

| מצב | מעבד | דגם | סוללה |
|---|---|---|---|
| ADB (טלפון דלוק) | ✅ | ✅ שם דגם | ✅ אחוז מדויק |
| Fastboot | חלקי | ✅ product | ⚠️ מתח (לא תמיד) |
| BROM / Preloader | ✅ | ❌ | ❌ |

הערה: אחוז סוללה ושם דגם הם מידע ברמת אנדרואיד — הם זמינים רק כשהטלפון דלוק (ADB).
במצב BROM/Preloader אין דרך לקרוא אותם, ולכן יוצג רק המעבד. הקריאה נעשית עם
`adb.exe` / `fastboot.exe` מתיקיית `tools`, ודורשת את דרייבר ה-ADB/Fastboot המתאים.

### סדר הזיהוי האוטומטי (מדורג)

1. **ADB** — נבדק ראשון: הערוץ העשיר ביותר (דגם, מעבד, אחוז סוללה מדויק).
2. **BROM/Preloader** — אם לא נמצא מכשיר ב-ADB ומופיע פורט MTK (VID `0E8D`):
   מוצגת הודעה "לא נמצא מכשיר במצב ADB", ומוצעת קריאת GPT דרך mtkclient
   (קריאה בלבד) שמזהה גם את שם המעבד.
3. **Fastboot** — אינו נבדק אוטומטית כלל: הוא פרוטוקול נפרד, והזיהוי בו נעשה
   רק בבקשת המשתמש מלשונית ⚡ Fastboot (כפתור "זהה מכשיר"), כדי שלא יתחרה
   בזיהוי ADB/BROM האוטומטי.

### דיאלוג בחירת כלי בפתיחה

בהפעלה נפתח דיאלוג צף "באיזה כלי לדבר עם המכשיר?" עם שלוש אופציות —
📱 ADB, ⚡ Fastboot, 🧬 mtkclient (BROM). לכל אופציה הסבר קצר וכפתור "הוראות"
(פתיחת מצב מפתחים/ניפוי באגים, כניסה ל-Fastboot, חיבור ב-BROM).
בחירה מעבירה ללשונית המתאימה ומריצה את הזיהוי של אותו כלי. אפשר לסגור
ולהמשיך בלי בחירה — הזיהוי האוטומטי רץ ברקע בכל מקרה.

### סנכרון שם המעבד לכותרת

שם המעבד מסונכרן לכותרת מצב המכשיר מכל ערוץ שבו הוא זוהה —
GPT של mtkclient, ADB (`ro.board.platform` / `ro.hardware` / serialno),
Fastboot (`getvar product`/`board`) ו-gettargetconfig — ונשאר מוצג
כל עוד המכשיר מחובר. הוא מזין אוטומטית גם לשדה platform בלשונית Scatter.

### העברה למחשב אחר / אריזה

התוכנה ניידת: כל הפלטים (logs, dumps, scatter, backups, bank) בנתיבים
יחסיים לתיקיית הפרויקט. כלי העבודה (mtkclient, adb, fastboot) ארוזים בתוך
`tools`, ולכן התלות היחידה במחשב היא הנתיב ל-Python הניידת. משנים אותו
באחת משתי דרכים:
1. משתנה סביבה `ASKATEROOV_PYTHON_ROOT` שמצביע על תיקיית MTKCliantPortable
   במחשב החדש.
2. עריכת הנתיב בראש `app/core/config.py`.
וכן עדכון הנתיב ב-`הסקטארוב.bat` (שימו לב: הקובץ ASCII-בלבד — השתמשו
בקיצורי 8.3 כמו `DOWNLO~1` לנתיבים בעברית). לא נדרשת קומפילציה —
מעתיקים את תיקיית הפרויקט + ה-runtime ומריצים את ה-.bat.

## עקרון מרכז השליטה

כל פעולה מול המכשיר (קריאה, שאיבה, צריבה, מחיקה, seccfg) נפתחת בחלון **"אישור פעולה"**

## מדריך לשוניות

### mtkclient
- **פורטים מחוברים (ניטור חי)** — טבלת פורטים עם כפתור 🔄 רענון ידני; מזהה BROM / Preloader (VID `0E8D`).
- **זיהוי מכשיר (דורש מכשיר במצב BROM/Preloader)** — זיהוי המכשיר וקריאת GPT (`mtk printgpt`), שמפענחת את טבלת המחיצות, מציגה אותה, ומזינה אוטומטית את שם המעבד ללשונית Scatter. אחרי קריאת GPT מוצעת בדיקת מצב אבטחה / בוטלאודר (קריאה בלבד).
- **דרייברים** — ⚙️ התקן דרייברים (usbdk מקומי), 🌐 הורדת דרייברי MediaTek VCOM, ו-🩺 בדיקת מצב הדרייברים (בודקת דרייבר MediaTek VCOM/PreLoader ו-UsbDk, שהם הנדרשים לגישה ל-BROM).
- **סביבת פייתון (בשביל mtkclient)** — 🔍 זהה סביבת פייתון ו-⬇️ התקן פייתון.

### שאיבה (Readback)
- **תיבות סימון** ליד כל מחיצה — מסמנים כמה שרוצים (או ☑ סמן הכל / ☐ נקה סימון) ושואבים ברצף ("שאב מחיצות מסומנות"). מוצג מספר המחיצות המסומנות והגודל הכולל; כפתור "טען GPT לרשימה" מרענן את הרשימה.
- שאיבת Preloader (קובץ בינארי) / כל המחיצות (`dumppreloader` / `rl` לתיקייה חדשה עם חותמת זמן).
- **גיבוי NVRAM / NVDATA** (IMEI, MAC, כיול) לתיקייה משותפת תחת `workspace\backups`. (שחזור: לשונית צריבה, מחיצת nvram/nvdata.)
- לכל שאיבה מחושב ונשמר סכום ביקורת **SHA256** לצד הקובץ.
- הקבצים נשמרים תחת `workspace\dumps`, וכפתור 📂 פתח תיקיית שאיבות פותח אותם.

### צריבה (Download)
- צריבת Image למחיצה (`mtk w`) עם:
  - **אימות גודל** מול גודל המחיצה לפני הצריבה.
  - **אזהרה מודגשת** למחיצות רגישות.
  - **גיבוי אוטומטי של המחיצה לפני צריבה** ל-`workspace\backups` (תיבת סימון, מופעלת כברירת מחדל).

### 📄 Scatter
- יוצר Scatter מלא תקני מה-GPT (ל-SP Flash Tool): `preloader` (EMMC_BOOT_1) + `pgpt` +
  כל מחיצות ה-GPT + `sgpt` — גם כש-printgpt לא מחזיר אותן.
- `nvram` מסומנת BINREGION (נשמרת ב-Format All), `super` ניתנת לצריבה.
- `block_size` מתעדכן אוטומטית לפי המעבד (MT65xx וכדומה: `0x20000`, מודרניים: `0x200000`).
- **שם המעבד הוא חובה:** הוא נכתב לשדה `platform`, לשם הקובץ
  (`Android_scatter_MT6580.txt`) ולקבוצה בבנק — כך שאין Scatter "בלי שם מעבד"
  וקובץ של מעבד אחד לא דורס של אחר.
- שם המעבד מזוהה אוטומטית מהמכשיר בעת "קרא GPT" (למשל `CPU: MT6580`).
- כלי בדיקה: **✅ אמת תקינות ל-SP Flash** ו-**👁️ תצוגה מקדימה**, ותיבת סימון לשמירה אוטומטית גם ל**בנק הסקטארים** תחת שם המעבד.

### 📱 ADB
- **דרייבר ADB** — ⬇️ הורדת דרייבר ADB ו-🩺 בדיקת דרייבר ADB.
- **בוטלאודר (דרך ADB)** — 🔍 בדוק מצב בוטלאודר, 🔓 פתח בוטלאודר, 🔒 נעל בוטלאודר (במכשיר עם ADB מורשה).
- **מידע על המכשיר (קריאה בלבד)** — ℹ️ קרא מידע: דגם, מעבד, גרסת אנדרואיד, מספר סידורי, מצב Verified Boot וסוללה.
- **ניהול אפליקציות** — 📦 התקן (APK · XAPK · APKM · APKS), 📋 רשימת אפליקציות מותקנות (כולל אפשרות להציג גם אפליקציות מערכת), ℹ️ מידע על האפליקציה, והסרה (🗑️ הסר מסומנות / לפי שם) עם אפשרויות עדכון (`-r`) והורדת גרסה (`-d`).
- **סייר קבצים (ADB)** — ניווט (⬆️ למעלה, 🏠 /sdcard, ↵ עבור, 🔄 רענון), 📋 הדבק ו-🗑️ מחק.
- **הרשאות ניהול מלאות למכשיר** (למשל אפליקציות סינון) — 👑 הענק בעלות מלאה (device owner) ו-🛡️ הפעל כמנהל-התקן (device admin).

### ⚡ Fastboot
- תקשורת עם המכשיר במצב **Fastboot** (פרוטוקול נפרד מ-BROM/Preloader, דרך `fastboot.exe`).
- **דרישות:** (1) `fastboot.exe` — ארוז בתוכנה ב-`tools` והתוכנה מאתרת אותו אוטומטית (גם PATH, ליד התיקייה הניידת, `platform-tools`, או משתנה `ASKATEROOV_FASTBOOT`); **אין בחירה ידנית של הקובץ** בממשק. (2) דרייבר **Android Bootloader Interface**. (3) לצריבה/מחיקה — בוטלאודר פתוח.
- **זיהוי ומידע (קריאה בלבד):** 🔎 זהה מכשיר (devices), ℹ️ מידע ומצב נעילה (getvar all), ❓ הוראות Fastboot.
- **צריבה / מחיקה (דורש בוטלאודר פתוח):** 🔥 צרב (flash), 🗑️ מחק (erase).
- **אתחול:** 🔄 הפעל מחדש (מערכת), 🚀 עבור למצב Fastboot.
- **דרייברים למצב Fastboot** (בתחתית הלשונית): ⬇️ הורדת דרייבר Fastboot ו-🩺 בדיקת דרייבר Fastboot.
- ⚠️ צריבה ב-Fastboot משתמשת בקובצי `.img` לפי שם מחיצה — **לא** דרך Scatter.

### 🔓 Bootloader
- **בדיקת מצב אבטחה / בוטלאודר (קריאה בלבד)** — 🔍 בדוק מצב אבטחה / בוטלאודר: מריץ `gettargetconfig` ומציג
  Secure Boot / DAA / SLA. מוצע אוטומטית אחרי קריאת GPT, וזמין גם בלחצן בלשונית.
- 🔓 Unlock / 🔒 Lock דרך `mtk da seccfg` (לפי ערוץ התקשורת הפעיל).

## מבנה הקוד

```
run.py                 # נקודת כניסה (רץ בפועל)
הסקטארוב.bat           # מפעיל את run.py עם ה-Python הניידת
app/
  main.py              # העלאת QApplication והחלון הראשי
  core/
    config.py          # נתיבים, גרסאות, מחיצות רגישות, איתור python/adb/fastboot
    logs.py            # מערכת לוגים מרכזית
    gpt_parser.py      # פענוח GPT (פלט mtk + קובץ בינארי)
    scatter.py         # מחולל Scatter מלא (עם שם מעבד חובה)
    scatter_bank.py    # בנק הסקטארים — ארכיון קובצי Scatter לפי מעבד/מכשיר
    checksums.py       # SHA256/MD5, גדלים
    safety.py          # אזהרות, אימות גודל/סכום
    mtk_bridge.py      # הרצת mtk.py עם פלט חי + עזרי progress
    jobs.py            # תוכניות עבודה (רצף שלבים), גיבוי לפני צריבה, גיבוי NVRAM, פעולות Fastboot
    port_monitor.py    # ניטור פורטים חי
    pyenv.py           # איתור סביבת Python/פייתון ניידת והתקנתה
    device_info.py     # מידע על המכשיר דרך ADB
    adb_boot.py        # בוטלאודר דרך ADB
    adb_files.py       # סייר קבצים וניהול אפליקציות דרך ADB
    apk_info.py        # פענוח APK / XAPK / APKM / APKS
    fastboot_bridge.py # הרצת fastboot.exe עם פלט חי
    drivers.py         # בדיקת דרייברים במחשב (קריאה בלבד)
  gui/
    bus.py             # אותות Qt (thread-safe)
    main_window.py     # החלון הראשי + כל הלשוניות + חלון אישור פעולה + הגדרות
    theme.py           # ערכות צבע (כחול עמוק / כהה) + שמירת הסדר הגמיש
    device_status.py   # כותרת מצב המכשיר
    icons.py           # סמלים מצוירים (גלגל שיניים, מידע, שאיבה, צריבה)
    logo.py            # הלוגו וסמל הבנק
tests/                 # בדיקות יחידה (run_tests.py — בלי pytest)
tools/                 # mtkclient, adb.exe, fastboot.exe (ארוזים)
workspace/             # dumps · scatter · backups · logs · scatter_bank
```

## בעיות נפוצות

| תופעה | פתרון |
|---|---|
| המכשיר לא מזוהה | נתק את הסוללה/כבה, חבר USB תוך כדי לחיצה על הכפתורים (BROM mode) |
| "mtkclient לא נמצא" | ודא שהנתיב ל-MTKCliantPortable נכון (`ASKATEROOV_PYTHON_ROOT`) |
| הדרייבר לא מותקן / המכשיר לא מזוהה ב-Fastboot | הרץ 🩺 בדיקת דרייבר בלשונית המתאימה, והשתמש בכפתור ההורדה שלידו |
| צריבה נכשלת | בדוק את קובץ ה-log ב-`workspace\logs`, וודא שה-Image תואם לגודל המחיצה |
