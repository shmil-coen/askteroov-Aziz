# הסקטארוב — תיאור התוכנה

**גרסה: 0.7.3**

תוכנה לניהול, שאיבה (Readback) וצריבה (Flash) של מכשירי MediaTek — ממשק גרפי בעברית מעל **mtkclient**, עם תמיכה ב-SP Flash Tool Scatter.

## ⚠️ אזהרות בטיחות

- **צריבת Preloader / LK שגויה עלולה להמית את המכשיר לצמיתות.**
- גבה תמיד לפני צריבה — התוכנה מגבה אוטומטית (אפשר לכבות בתיבת הסימון בלשונית הצריבה).
- מחיצות רגישות (preloader, lk, nvram, nvdata, seccfg, frp, efuse ועוד) מציגות אזהרה מודגשת לפני פעולה.
- אין ערבות — השימוש באחריותך בלבד.

## הפעלה

לחיצה כפולה על **`הסקטארוב.bat`** בתיקיית הפרויקט, או בשורת פקודה:

```bat
cd %USERPROFILE%\Desktop\
```

`run.py` הוא נקודת הכניסה בפועל: הוא מוסיף את תיקיית הפרויקט ל-`sys.path` ומעלה את החלון הראשי.

## כותרת מצב מכשיר (מעל הלשוניות)

מעל שורת הלשוניות מוצגת כותרת "מצב מכשיר" עם חיווי חי: דגם, מעבד, **בוטלאודר** (מתעדכן אחרי בדיקת אבטחה או קריאת מידע),
בורר **ערוץ תקשורת** ואחוז/מתח סוללה מסונכרן (הסוללה מוצגת רק כשיש נתון).
"ℹ️ קרא מידע" בלשונית ADB מעדכן גם את הכותרת (דגם, מעבד, סוללה) — גם כשערוץ התקשורת לא מתעדכן לבד. ב-Fastboot מוצג כמעבד רק שם מעבד אמיתי (MTxxxx), לא שם הדגם. העדכון אוטומטי (כולל בדיקה תקופתית) כשמכשיר מתחבר/מתנתק.
מתחת לכותרת נמצא מד ההתקדמות, ומתחתיו הלשוניות. מה שמוצג תלוי במצב החיבור:

| מצב | מעבד | דגם | סוללה |
|---|---|---|---|
| ADB (טלפון דלוק) | ✅ | ✅ שם דגם | ✅ אחוז מדויק |
| Fastboot | חלקי | ✅ product | ⚠️ מתח (לא תמיד) |
| BROM / Preloader | ✅ | ❌ | ❌ |

הערה: אחוז סוללה ושם דגם הם מידע ברמת אנדרואיד — הם זמינים רק כשהטלפון דלוק (ADB).
במצב BROM/Preloader אין דרך לקרוא אותם, ולכן יוצג רק המעבד. הקריאה נעשית עם
`adb.exe` / `fastboot.exe` מתיקיית `tools`, ודורשת את דרייבר ה-ADB/Fastboot המתאים.

### ערוץ תקשורת (בורר בכותרת)

שדה **ערוץ תקשורת** בכותרת: **אוטומטי** / **ADB** / **Fastboot** / **mtkclient (BROM)**.
- **אוטומטי** — מתחבר דרך הערוץ הראשון שמזהה את המכשיר, ונשאר בו.
- ערוץ מפורש — הזיהוי האוטומטי ישתמש רק בו ולא ינסה דרכים אחרות.
פעולות שקיימות בכמה ערוצים (בדיקת בוטלאודר, Unlock/Lock) מנותבות לפי הערוץ הפעיל.
פעולה שדורשת BROM (למשל seccfg) מציעה לעבור לערוץ mtkclient אם הערוץ הפעיל אחר.
אם אין ערוץ פעיל — מוצגת הודעה "אין ערוץ תקשורת פעיל".

### סדר הזיהוי האוטומטי (מדורג)

1. **ADB** — נבדק ראשון: הערוץ העשיר ביותר (דגם, מעבד, אחוז סוללה מדויק).
2. **BROM/Preloader** — אם לא נמצא מכשיר ב-ADB ומופיע פורט MTK (VID `0E8D`):
   מוצגת הודעה "לא נמצא מכשיר במצב ADB", ומוצעת קריאת GPT דרך mtkclient
   (קריאה בלבד) שמזהה גם את שם המעבד.
3. **Fastboot** — אינו נבדק אוטומטית כלל: הוא פרוטוקול נפרד, והזיהוי בו נעשה
   רק בבקשת המשתמש מלשונית ⚡ Fastboot (כפתור "זהה מכשיר"), כדי שלא יתחרה
   בזיהוי ADB/BROM האוטומטי.

### דיאלוג בחירת כלי בפתיחה — אין חיפוש אוטומטי לפני בחירה

בפתיחה **אין שום חיפוש מכשיר** (ערוץ התקשורת: "לא נבחר"). נפתח דיאלוג "באיזה כלי לדבר עם המכשיר?" עם 📱 ADB, ⚡ Fastboot, 🧬 mtkclient (BROM) — לכל אחד הסבר וכפתור "הוראות" — וכפתור **🤷 אני לא יודע עדיין**, ששואל: "במכשיר שלך מופעל מצב מפתחים עם ניפוי באגים ב-USB?"
- **כן, מופעל** ← ADB, והחיפוש מתחיל.
- **לא, אבל אפשר להפעיל** ← הוראות הפעלה, ואז ADB.
- **לא / המכשיר לא נדלק** ← הוראות חיבור ב-BROM, ומעבר אוטומטי ל-mtkclient.
סגירת הדיאלוג (X) — אין חיפוש עד שבוחרים ערוץ בשדה "ערוץ תקשורת" בכותרת.

### סנכרון שם המעבד לכותרת

שם המעבד מסונכרן לכותרת מצב המכשיר מכל ערוץ שבו הוא זוהה —
GPT של mtkclient, ADB (`ro.board.platform` / `ro.hardware` / serialno),
Fastboot (`getvar product`/`board`) ו-gettargetconfig — ונשאר מוצג
כל עוד המכשיר מחובר. הוא מזין אוטומטית גם לשדה platform בלשונית Scatter.

### העברה למחשב אחר / אריזה

**איפה התוכנה מחפשת פייתון (להרצת mtkclient), לפי הסדר:** התיקייה הניידת (`ASKATEROOV_PYTHON_ROOT` / נתיב ברירת המחדל) ← בגרסה מקומפלת: תיקייה `MTKCliantPortable` ליד קובץ ה-exe ← פייתון שהותקן למשתמש (`%LOCALAPPDATA%\Programs\Python\Python312`, גם זה שהתוכנה מתקינה) ← פייתון ב-PATH. פייתון שהותקן אוטומטית נכנס לשימוש מיד, בלי להפעיל מחדש.

**גרסה מקומפלת (exe יחיד):** הנתונים והכלים נשמרים ב-`C:\ProgramData\Askateroov` (תיקייה מוסתרת ישר מתחת לכונן, משותפת לכל המשתמשים, לא דורשת הרשאת מנהל): `workspace` (שאיבות, לוגים, בנק, גיבויים) ו-`tools` — שנפרסים מתוך ה-exe פעם אחת לכל גרסה. ה-exe עצמו יכול לשבת בכל מקום ולזוז. בהרצה מקוד המקור — הכול נשאר בתיקיית הפרויקט.

התוכנה ניידת: כל הפלטים (logs, dumps, scatter, backups, bank) בנתיבים
יחסיים לתיקיית הפרויקט. כלי העבודה (mtkclient, adb, fastboot) ארוזים בתוך
`tools`, ולכן התלות היחידה במחשב היא הנתיב ל-Python הניידת. משנים אותו
באחת משתי דרכים:
1. משתנה סביבה `ASKATEROOV_PYTHON_ROOT` שמצביע על תיקיית MTKCliantPortable
   במחשב החדש.
2. עריכת הנתיב בראש `app/core/config.py`.
וכן עדכון הנתיב ב-`הסקטארוב.bat` (שימו לב: הקובץ ASCII-בלבד — השתמשו
בקיצורי 8.3 כמו `DOWNLO~1` לנתיבים בעברית). לא נדרשת קומפילציה —
מעתיקים את תיקיית הפרויקט + ה-runtime ומריצים את ה-.bat.

## עקרון מרכז השליטה

כל פעולה מול המכשיר (קריאה, שאיבה, צריבה, מחיקה, seccfg) נפתחת בחלון **"אישור פעולה"**
שמציג את פקודות ה-mtk המדויקות, היעד וההערות — ורצה רק אחרי "אשר והרץ".
פעולה אחת בכל רגע; כפתור ⬟ בטל פעולה — בתחילת החלון.
פעולות מרובות שלבים (גיבוי ← צריבה, שאיבת כמה מחיצות) נעצרות בשלב הראשון שנכשל.

**ניסיונות חוזרים (שאיבה / גיבוי NVRAM):** עד 3 ניסיונות לכל שלב. בכל ניסיון mtkclient ממתין לחיבור המכשיר ("Waiting for PreLoader VCOM") **עד 45 שניות**; אם המכשיר לא התחבר — הניסיון נחשב "כשל בחיבור" ומתחיל מיד ניסיון נוסף עם עוד 45 שניות. גם הודעת "Please disconnect… reconnect", כשל handshake ונפילת חיבור USB באמצע (`USBError` / `Input/Output Error`) נחשבים כשל חיבור. אחרי 3 כשלי חיבור הפעולה נעצרת ומוצג חלון "החיבור למכשיר נכשל" עם הוראות חיבור במצב BROM וכפתורים **ביטול** / **🔄 ניסיון חוזר**. כשל רגיל (לא בחיבור) — המתנה של 2 שניות וניסיון נוסף.

## 🔧 דרייברים — למה מכשיר לפעמים לא מזוהה, ואיך התוכנה מטפלת בזה

Windows מצמיד דרייבר לפי המזהה שהמכשיר מכריז עליו (VID/PID), ורק אם המזהה כתוב בקובץ ה-INF של הדרייבר (הקובץ חתום — אי אפשר להוסיף לו מזהים). טלפונים זולים עם MediaTek מעתיקים מזהים של יצרנים אחרים (למשל `0BB4:0C01` של HTC ב-Fastboot), ולכן אף דרייבר של יצרן לא מכיר אותם.

- **אין דרייבר חתום "אוניברסלי"** שמתאים לפי סוג הממשק (ADB = `FF/42/01`, Fastboot = `FF/42/03`) — גם לא ב-Windows. דרייברים כמו Universal ADB Driver הם בפועל רשימת מזהים (ישנה, 2012), ולא תופסים מכשירים כמו `0BB4:0C01` בממשק יחיד — ולכן לא נכללו. יצירת דרייבר כזה מחייבת להוסיף למחשב תעודת אבטחה משלנו (כמו Zadig) — פולשני מדי.
- **⚙️ התקנת דרייבר ADB / Fastboot**: מתקין את דרייבר ה-ADB/Fastboot של MediaTek שארוז בתוכנה (`tools\fastboot_driver`).
- **🔧 תקן דרייבר למכשיר המחובר** (בלשוניות mtkclient, ADB ו-Fastboot): מאתר התקן Android/MediaTek שמחובר בלי דרייבר ומצמיד לו את הדרייבר המתאים מהתוכנה — כמו "עדכן מנהל התקן ← יש לי תקליטור" — לפי סוג הממשק: Fastboot / ADB / BROM-Preloader. רץ דרך `tools\fix_driver.ps1` בהרשאת מנהל.
- **🩺 בדיקת דרייבר**: מציגה בפשטות אם הדרייבר מותקן, והאם מחובר עכשיו מכשיר (ואם כן — האם Windows מצליח לדבר איתו). כשצריך — שורת "מה לעשות".

## מדריך לשוניות

### mtkclient
- **פורטים מחוברים (ניטור חי)** — טבלת פורטים (פורט · תיאור · מצב · VID · PID) שמתעדכנת אוטומטית, וכפתור **🔄 רענן עכשיו** למקרה שלא התעדכנה; מזהה BROM / Preloader (VID `0E8D`).
- **זיהוי מכשיר (דורש מכשיר במצב BROM/Preloader)** — זיהוי המכשיר וקריאת GPT (`mtk printgpt`), שמפענחת את טבלת המחיצות, מציגה אותה, ומזינה אוטומטית את שם המעבד ללשונית Scatter. אחרי קריאת GPT מוצעת בדיקת מצב אבטחה / בוטלאודר (קריאה בלבד).
- **דרייברים** — ⚙️ התקנת דרייבר UsbDk (מתוך התוכנה, `tools\usbdk.msi`) ⚙️ התקנת דרייבר MediaTek VCOM (מתוך התוכנה, מהתיקייה `tools\mediatek_driver` — קובצי INF דרך pnputil עם הרשאת מנהל, או קובץ התקנה exe/msi), ולצד כל אחד כפתור קטן עם סמל כדור אינטרנט מצויר (`globe_icon` ב-`icons.py`) להורדה (UsbDk — GitHub הרשמי של Daynix; MediaTek — mtkdriver.com), ו-🩺 בדיקת מצב הדרייברים (בודקת דרייבר MediaTek VCOM/PreLoader ו-UsbDk, שהם הנדרשים לגישה ל-BROM).
- **סביבת פייתון (בשביל mtkclient)** — ⚙️ **התקן פייתון וספריות ל-mtkclient (אוטומטי)**: מוריד את מתקין פייתון 3.12 הרשמי מ-python.org, מריץ אותו במצב אוטומטי עם PATH מסומן (למשתמש הנוכחי, בלי הרשאת מנהל), ומתקין את הספריות של mtkclient (חובה: pyusb, pyserial, pycryptodome, pycryptodomex, colorama; רשות: capstone, keystone-engine, fusepy, mock). אם פייתון כבר מותקן — מתקין רק את הספריות. כשהתוכנה מזהה שאין פייתון, היא מציעה את ההתקנה בעצמה (אחרי דיאלוג הפתיחה). אם ההתקנה נכשלת — דיאלוג עם 4 צעדי התקנה ידנית (כולל סימון "Add python.exe to PATH") וחלופת הפייתון הנייד. 🔍 זהה סביבת פייתון, ⬇️ הורדת פייתון להתקנה (פותח את דף ההורדה הרשמי — ההתקנה עצמה ידנית) ו-⬇️ הורדת פייתון נייד (MTKClient Portable — קובץ zip ב-Google Drive עם mtkclient ופייתון נייד, בלי התקנה).

### שאיבה (Readback)
- **תיבות סימון** ליד כל מחיצה — מסמנים כמה שרוצים (או ☑ סמן הכל / ☐ נקה סימון) ושואבים ברצף ("שאב מחיצות מסומנות"). מוצג מספר המחיצות המסומנות והגודל הכולל; כפתור "טען GPT לרשימה" מרענן את הרשימה.
- שאיבת Preloader (קובץ בינארי) / כל המחיצות (`dumppreloader` / `rl` לתיקייה חדשה עם חותמת זמן).
- **גיבוי NVRAM / NVDATA** (IMEI, MAC, כיול) לתיקייה משותפת תחת `workspace\backups`. (שחזור: לשונית צריבה, מחיצת nvram/nvdata.)
- לכל שאיבה מחושב ונשמר סכום ביקורת **SHA256** לצד הקובץ.
- הקבצים נשמרים תחת `workspace\dumps`, וכפתור 📂 פתח תיקיית שאיבות פותח אותם.

### צריבה (Download)
- צריבת Image למחיצה (`mtk w`) עם:
  - **אימות גודל** מול גודל המחיצה לפני הצריבה.
  - **אזהרה מודגשת** למחיצות רגישות.
  - **גיבוי אוטומטי של המחיצה לפני צריבה** ל-`workspace\backups` (תיבת סימון, מופעלת כברירת מחדל).

### 📄 Scatter
- יוצר Scatter מלא תקני מה-GPT (ל-SP Flash Tool): `preloader` (EMMC_BOOT_1) + `pgpt` +
  כל מחיצות ה-GPT + `sgpt` — גם כש-printgpt לא מחזיר אותן.
- `nvram` מסומנת BINREGION (נשמרת ב-Format All), `super` ניתנת לצריבה.
- `block_size` מתעדכן אוטומטית לפי המעבד (MT65xx וכדומה: `0x20000`, מודרניים: `0x200000`).
- **שם המעבד הוא חובה:** הוא נכתב לשדה `platform`, לשם הקובץ
  (`Android_scatter_MT6580.txt`) ולקבוצה בבנק — כך שאין Scatter "בלי שם מעבד"
  וקובץ של מעבד אחד לא דורס של אחר.
- שם המעבד מזוהה אוטומטית מהמכשיר בעת "קרא GPT" (למשל `CPU: MT6580`).
- כלי בדיקה: **✅ אמת תקינות ל-SP Flash** ו-**👁️ תצוגה מקדימה**, ותיבת סימון לשמירה אוטומטית גם ל**בנק הסקטארים** תחת שם המעבד.
- מצבי SP Flash (Download Only / Format All) — **בתכנון**, עדיין לא ממומשים.

### 📱 ADB
- **דרייבר ADB** — ⬇️ הורדת דרייבר ADB ו-🩺 בדיקת דרייבר ADB.
- **בוטלאודר (דרך ADB)** — 🔍 בדוק מצב בוטלאודר, 🔓 פתח בוטלאודר, 🔒 נעל בוטלאודר (במכשיר עם ADB מורשה).
- **🚀 עבור למצב Fastboot** — מאתחל את המכשיר הדלוק ל-Fastboot (`adb reboot bootloader`), ממתין עד 60 שניות לזיהויו ב-Fastboot ומעביר את ערוץ התקשורת ל-Fastboot. הבוטלאודר לא נפתח ולא ננעל, והנתונים לא נמחקים.
- **מידע על המכשיר (קריאה בלבד)** — ℹ️ קרא מידע: דגם, מעבד, גרסת אנדרואיד, מספר סידורי, מצב Verified Boot (מזהה גם ערכים בשמות צבע: green/yellow/orange/red) וסוללה.
- **ניהול אפליקציות** — 📦 התקן (APK · XAPK · APKM · APKS), 📋 רשימת אפליקציות מותקנות (כולל אפשרות להציג גם אפליקציות מערכת), ℹ️ מידע על האפליקציה, והסרה (🗑️ הסר מסומנות / לפי שם) עם אפשרויות עדכון (`-r`) והורדת גרסה (`-d`).
- **סייר קבצים (ADB)** — ניווט (⬆️ למעלה, 🏠 /sdcard, ↵ עבור, 🔄 רענון), 📋 הדבק ו-🗑️ מחק.
- **הרשאות ניהול מלאות למכשיר** (למשל אפליקציות סינון) — 👑 הענק בעלות מלאה (device owner) ו-🛡️ הפעל כמנהל-התקן (device admin).

### ⚡ Fastboot
- תקשורת עם המכשיר במצב **Fastboot** (פרוטוקול נפרד מ-BROM/Preloader, דרך `fastboot.exe`).
- **דרישות:** (1) `fastboot.exe` — ארוז בתוכנה ב-`tools` והתוכנה מאתרת אותו אוטומטית (גם PATH, ליד התיקייה הניידת, `platform-tools`, או משתנה `ASKATEROOV_FASTBOOT`); **אין בחירה ידנית של הקובץ** בממשק. (2) דרייבר **Android Bootloader Interface**. (3) לצריבה/מחיקה — בוטלאודר פתוח.
- **זיהוי ומידע (קריאה בלבד):** 🔎 זהה מכשיר (devices), ℹ️ מידע ומצב נעילה (getvar all), ❓ הוראות Fastboot.
- **צריבה / מחיקה (דורש בוטלאודר פתוח):** 🔥 צרב (flash), 🗑️ מחק (erase).
- **אתחול:** 🔄 הפעל מחדש (מערכת), 🚀 עבור למצב Fastboot.
- **דרייברים למצב Fastboot** (בתחתית הלשונית): ⚙️ התקנת דרייבר Fastboot (מתוך התוכנה — מהתיקייה `tools\fastboot_driver`, עם הרשאת מנהל), ⬇️ הורדת דרייבר Fastboot (הדרייבר הרשמי של Google) ו-🩺 בדיקת דרייבר Fastboot.
  הדרייבר הארוז (`android_winusb.inf` של MediaTek) מכסה Android Bootloader Interface ו-ADB למכשירים שמזדהים כ-MediaTek (VID `0E8D`); מכשיר שמזדהה ב-Fastboot כ-Google (VID `18D1`) צריך את הדרייבר של Google.
- ⚠️ צריבה ב-Fastboot משתמשת בקובצי `.img` לפי שם מחיצה — **לא** דרך Scatter.

### 🔓 Bootloader
- **בדיקת מצב אבטחה / בוטלאודר (קריאה בלבד)** — 🔍 בדוק מצב אבטחה / בוטלאודר, לפי ערוץ התקשורת הפעיל:
  ADB (`getprop`) · Fastboot (`getvar`) · mtkclient (`gettargetconfig` — מציג Secure Boot / DAA / SLA).
  מוצע אוטומטית אחרי קריאת GPT, וזמין גם בלחצן בלשונית.
- 🔓 Unlock / 🔒 Lock — לפי ערוץ התקשורת הפעיל: mtkclient (`seccfg`) · Fastboot (`flashing`).
- ⚠️ פתיחת הבוטלאודר מוחקת את כל הנתונים מהמכשיר.

### 📜 לוג
- פלט חי מכל הפקודות, מד התקדמות בזמן אמת, וייצוא לקובץ טקסט.
- לוג מלא נשמר אוטומטית תחת `workspace\logs\log_*.txt` (גם בהפעלה הבאה מוצג הלוג מההפעלה הקודמת).

### מד התקדמות וכשלים
- בכל פעולה מד ההתקדמות זז: אחוזים כשה-mtk מדווח עליהם, אחרת מצב "רץ" נע.
- פעולה שנכשלה מציגה חלון שגיאה ברור (כולל השגיאה האחרונה מהלוג) — כדי שלא
  ייחשב בטעות שהיא הצליחה.

## מבנה הקוד

```
run.py                 # נקודת כניסה (רץ בפועל)
הסקטארוב.bat           # מפעיל את run.py עם ה-Python הניידת
app/
  main.py              # העלאת QApplication והחלון הראשי
  core/
    config.py          # נתיבים, גרסאות, מחיצות רגישות, איתור python/adb/fastboot
    logs.py            # מערכת לוגים מרכזית
    gpt_parser.py      # פענוח GPT (פלט mtk + קובץ בינארי)
    scatter.py         # מחולל Scatter מלא (עם שם מעבד חובה)
    scatter_bank.py    # בנק הסקטארים — ארכיון קובצי Scatter לפי מעבד/מכשיר
    checksums.py       # SHA256/MD5, גדלים
    safety.py          # אזהרות, אימות גודל/סכום
    mtk_bridge.py      # הרצת mtk.py עם פלט חי + עזרי progress
    jobs.py            # תוכניות עבודה (רצף שלבים), גיבוי לפני צריבה, גיבוי NVRAM, פעולות Fastboot
    port_monitor.py    # ניטור פורטים חי
    pyenv.py           # איתור סביבת Python/פייתון ניידת והתקנתה
    device_info.py     # מידע על המכשיר דרך ADB
    adb_boot.py        # בוטלאודר דרך ADB
    adb_files.py       # סייר קבצים וניהול אפליקציות דרך ADB
    apk_info.py        # פענוח APK / XAPK / APKM / APKS
    fastboot_bridge.py # הרצת fastboot.exe עם פלט חי
    pyinstall.py       # התקנה אוטומטית של פייתון + הספריות של mtkclient
    drivers.py         # בדיקת דרייברים במחשב (קריאה בלבד — pnputil / קובצי INF; VCOM מזוהה לפי ספק MediaTek + מחלקת יציאות COM)
  gui/
    bus.py             # אותות Qt (thread-safe)
    main_window.py     # החלון הראשי + כל הלשוניות + חלון אישור פעולה + הגדרות
    theme.py           # ערכות צבע (כחול עמוק / כהה) + שמירת הסדר הגמיש
    device_status.py   # כותרת מצב המכשיר
    icons.py           # סמלים מצוירים (גלגל שיניים, מידע, שאיבה, צריבה)
    logo.py            # הלוגו וסמל הבנק
tests/                 # בדיקות יחידה (run_tests.py — בלי pytest)
tools/                 # mtkclient, adb.exe, fastboot.exe, usbdk.msi, mediatek_driver (VCOM), fastboot_driver, fix_driver.ps1 (ארוזים)
workspace/             # dumps · scatter · backups · logs · scatter_bank
```

## בעיות נפוצות

| תופעה | פתרון |
|---|---|
| המכשיר לא מזוהה | נתק את הסוללה/כבה, חבר USB תוך כדי לחיצה על הכפתורים (BROM mode) |
| "mtkclient לא נמצא" | ודא שהנתיב ל-MTKCliantPortable נכון (`ASKATEROOV_PYTHON_ROOT`) |
| הדרייבר לא מותקן / המכשיר לא מזוהה ב-Fastboot | הרץ 🩺 בדיקת דרייבר בלשונית המתאימה, והשתמש בכפתור ההורדה שלידו |
| צריבה נכשלת | בדוק את קובץ ה-log ב-`workspace\logs`, וודא שה-Image תואם לגודל המחיצה |
